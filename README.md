# Proyecto: TaskFlow API

**TaskFlow API** será una API REST desarrollada con FastAPI para crear y administrar tareas personales o de un equipo pequeño.

El objetivo académico no será construir un gestor de proyectos completo, sino disponer de una aplicación realista y fácil de verificar sobre la cual implementar posteriormente un pipeline completo de CI/CD.

## Alcance funcional

La aplicación permitirá:

- Crear una tarea.
- Consultar todas las tareas.
- Consultar una tarea por ID.
- Modificar una tarea.
- Cambiar el estado de una tarea.
- Eliminar una tarea.
- Filtrar tareas por estado o prioridad.
- Consultar la salud de la aplicación.
- Acceder a la documentación OpenAPI generada automáticamente.

No se incluirán inicialmente:

- Interfaz web.
- Registro de usuarios.
- Autenticación o autorización.
- Notificaciones.
- Archivos adjuntos.
- Integraciones externas.
- Colaboración entre usuarios.

Esto mantiene el proyecto pequeño y concentra el esfuerzo principal en el diseño y la implementación del pipeline de CI/CD.
